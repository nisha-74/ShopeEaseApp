### ShopEaseApp – Modern E-Commerce Android Application

**ShopEaseApp** is a modern e-commerce Android application built using **Kotlin and Jetpack Compose**. The app provides a smooth and user-friendly shopping experience where users can browse products, explore categories, view product details, and manage their shopping cart.

The application follows **MVVM architecture** with a clean and scalable project structure. It uses modern Android development practices such as **Jetpack Compose, Kotlin Coroutines, StateFlow, Hilt Dependency Injection, Retrofit, and Room Database**.

### Key Features

* 🛍️ Browse products and product categories
* 🔍 Search and explore products
* ❤️ Add products to favorites
* 🛒 Add and remove products from the shopping cart
* 📦 View detailed product information
* 💰 Display product prices and details
* 🎨 Modern and responsive Jetpack Compose UI
* 🌙 Light and dark theme support
* ⚡ Reactive UI using StateFlow and Coroutines
* 💾 Local data persistence using Room Database
* 🌐 REST API integration using Retrofit
* 💉 Dependency Injection using Hilt

### Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose, Material 3
* **Architecture:** MVVM / Clean Architecture
* **Dependency Injection:** Hilt
* **Networking:** Retrofit
* **Database:** Room
* **Asynchronous Programming:** Kotlin Coroutines & Flow
* **State Management:** StateFlow
* **Image Loading:** Coil
* **Build System:** Gradle

The goal of **ShopEaseApp** is to demonstrate how to build a scalable, maintainable, and modern Android e-commerce application using the latest Android development technologies and best practices.
